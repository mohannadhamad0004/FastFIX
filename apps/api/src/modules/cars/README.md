# cars module

Registered cars per customer and their maintenance history.

| File | Purpose |
| --- | --- |
| `cars.routes.js` | Express router: URLs and which controller handles them |
| `cars.controller.js` | Reads the request, calls the service, sends the response |
| `cars.service.js` | Business logic |
| `cars.model.js` | Database queries for this module |
