# certification module

Document upload (certificates, licenses, truck details) for mechanics, shop owners and tow companies, and the admin approval workflow.

| File | Purpose |
| --- | --- |
| `certification.routes.js` | Express router: URLs and which controller handles them |
| `certification.controller.js` | Reads the request, calls the service, sends the response |
| `certification.service.js` | Business logic |
| `certification.model.js` | Database queries for this module |
