# certification (mobile)

Mechanics, shop owners and tow companies upload certificates, licenses or truck details and follow their verification status.

Mirrors `apps/web/src/features/certification`.

| Path | Purpose |
| --- | --- |
| `screens/` | Screens for this feature |
| `components/` | UI used only by this feature |
| `api.js` | Calls to apps/api for this feature |
