# marketplace (mobile)

Parts, accessories, motors and headlights sold by shop owners. Shows which parts fit the customer's car, including parts shared across models, and the 3D preview of accessories on the car.

Mirrors `apps/web/src/features/marketplace`.

| Path | Purpose |
| --- | --- |
| `screens/` | Screens for this feature |
| `components/` | UI used only by this feature |
| `api.js` | Calls to apps/api for this feature |
