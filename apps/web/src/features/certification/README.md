# certification

Mechanics, shop owners and tow companies upload certificates, licenses or truck details and follow their verification status.

| Path | Purpose |
| --- | --- |
| `pages/` | Route-level screens for this feature |
| `components/` | UI used only by this feature (with `*.module.css` styles) |
| `api.js` | Calls to apps/api for this feature |
| `types.js` | JSDoc type definitions for this feature's data |
