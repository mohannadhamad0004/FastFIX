# diagnosis

Customer uploads a photo, video or audio of a car problem and sees the preliminary AI diagnosis: observations, likely faults ranked by probability, urgency, and what to check first. Mechanics confirm or correct it.

| Path | Purpose |
| --- | --- |
| `pages/` | Route-level screens for this feature |
| `components/` | UI used only by this feature (with `*.module.css` styles) |
| `api.js` | Calls to apps/api for this feature |
| `types.js` | JSDoc type definitions for this feature's data |
